# Don't Answer — public downloads

This repository contains **binary Windows releases only** for **Don't Answer — Забуте село**, distributed through ERA Launcher.

- The game source code lives in a separate **private** repository.
- Release archives are versioned: `dont-answer-VERSION-windows-x64.zip`.
- Each archive has a matching `.sha256` checksum file.
- Releases are promoted here only after an explicit manual approval step.
- ERA Launcher obtains the approved version from its **signed game catalog**; creating a GitHub Release here does **not** publish or update a game in ERA on its own.

## Downloads

When the first release is available, find it under [Releases](https://github.com/wntbf/dont-answer-downloads/releases).

The GitHub-hosted ZIP contains `DontAnswer.exe`, with the game's web assets embedded. The executable contains compiled program code, but the original source files and development history are not shared here.
